Open source

warehouse-context-mcpreleased

An MCP server that gives AI agents governed context about a data warehouse: what each table means, where it comes from, how fresh it is, and a read-only way to query it. Snowflake, Databricks and DuckDB; from Claude, Codex or VS Code.

Every query is treated as hostile. Only allow-listed SQL runs, every column is resolved against the live schema, and PII is masked inside the SQL so values never leave the warehouse. Two independent adversarial reviews tried to break it; their attacks now run on every commit.
